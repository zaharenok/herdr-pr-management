# herdr-pr-management

Публичный полигон для [herdr-pr-checker](https://github.com/zaharenok) — плагина herdr, который:

- **Inbound**: подхватывает новые pull request'ы этого репозитория, создаёт карточку на доске herdr-board и отдаёт её агенту — тот ревьюит изменения (дифф + тесты) и мержит (APPLY) или отклоняет (REJECT) с.reasoning в комментарии карточки.
- **Outbound**: локально готовую ветку можно «активировать» — агент опубликует её как GitHub PR и будет отслеживать статус.

## Как это выглядит

1. Вы открываете PR в этот репозиторий.
2. В течение ~5 минут (или по команде `prcheck once`) появляется карточка `PR #N: ...` в колонке **PR Review** доски `pr`.
3. Агент в видимой панели herdr проверяет изменения и оставляет вердикт: `PR #N: APPLY|REJECT — причина`.
4. APPLY → PR мержится сквошем автоматически.

Плагин никогда не форсит и не мержит без вердикта агента.
